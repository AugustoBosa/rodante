# 10 — Glossário e fontes

[← Índice](README.md)

## Glossário
| Termo | Significado |
|---|---|
| BIM | Modelo paramétrico único do qual saem lista de materiais, desenhos e arquivos de fabricação. Ver [06](06-bim-e-ifc.md) |
| BOM | Bill of Materials, lista de materiais |
| Rear / front / quad | Cadeira de apoio traseiro / dianteiro / quatro membros. Ver [03](03-tipos-e-biomecanica.md) |
| B-rep, OCCT | Modelagem de sólidos exata; OpenCascade Technology é o kernel open source. Ver [05](05-ferramentas-cad-web.md) |
| CSG / mesh | Geometria por malha e booleanas (JSCAD, OpenSCAD); exporta STL, não STEP de qualidade |
| STL / STEP | Malha para impressão / sólido CAD para usinagem e troca |
| IFC | Formato aberto de BIM de construção |
| IVDD, DM | Doença do disco intervertebral, mielopatia degenerativa |
| Sela / cradle | Suporte de corpo (peça impressa ou tecido) |
